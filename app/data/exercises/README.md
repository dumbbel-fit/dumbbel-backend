# Exercise data

From https://github.com/hasaneyldrm/exercises-dataset (MIT, see LICENSE): exercise names, body parts, muscles,
equipment and step-by-step instructions (English and Hindi kept here).

**Media:** the GIFs and images are not copied here. The app links to them in the exercises-dataset repo through
jsDelivr (`EXERCISE_MEDIA_BASE`, default `https://cdn.jsdelivr.net/gh/hasaneyldrm/exercises-dataset@main`).
The repo marks the media © Gym visual (https://gymvisual.com/), so the app always shows that credit under a GIF.
The owner of DUMBBEL.fit approved using it (26 Nov 2026). Set `EXERCISE_MEDIA_BASE` to an empty value to switch media off.
